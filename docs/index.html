使い方・インストール

WindowsのEdgeまたはChromeで開いてください。初めに「音楽フォルダを登録」を押し、歌手のフォルダをまとめた親フォルダを選びます。アクセスは読み取り専用です。

Tabで項目を移動し、ボタンはEnterまたはスペース、再生方法は矢印キーで選べます。フォルダを選んだ後は「再生」を押してください。曲一覧のボタンはその曲を再生します。

追加曲は「曲一覧を再読み込み」で反映します。サブフォルダもそれぞれ一覧表示します。空フォルダは0曲、MP3以外は対象外です。曲はフォルダ名・曲名の自然順に並びます。

ブラウザのメニューから「アプリをインストール」を選ぶとデスクトップから起動できます。初回は通信が必要です。音楽はコピーせず、毎回元ファイルを読みます。外付けドライブは接続しておいてください。

ブラウザのデータ削除などで登録や権限が失われた場合は「アクセスを再許可」またはフォルダの再設定を使います。

オフライン利用の準備を確認しています。
