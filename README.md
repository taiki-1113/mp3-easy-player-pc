# MP3かんたんプレイヤー PC

WindowsのEdge／Chrome向けMP3プレーヤーPWAです。キーボードとスクリーンリーダーでの利用を想定しています。

[プレーヤーを開く](https://taiki-1113.github.io/mp3-easy-player-pc/)

## 使い方

1. 「音楽フォルダを登録」で、歌手のフォルダをまとめた親フォルダを選びます。
2. 「すべての曲」または「フォルダ別」を選びます。フォルダは別画面で選択します。
3. 順番再生／シャッフル再生を選び、「再生」を押します。曲一覧からの個別再生もできます。
4. 曲を追加したら「曲一覧を再読み込み」を押します。権限が失効した場合は「アクセスを再許可」またはフォルダの再設定を使います。

Tabで移動し、ボタンはEnter／スペース、再生方法は矢印キーで操作できます。フォルダ選択後は自動再生しません。前曲・次曲、曲末の自動切り替え、末尾から先頭への繰り返しに対応します。

ブラウザのメニューからアプリをインストールすると、デスクトップから起動できます。初回準備には通信が必要です。

## ファイルと保存

File System Access APIを読み取り専用で使用します。MP3本体はアプリ内へコピーせず、再生時に元ファイルを直接読みます。ファイルの削除・移動・編集機能はありません。IndexedDBには親フォルダのハンドルだけを保存します。音楽を外部サーバーへ送信しません。

起動時にアクセス許可があれば一覧を自動取得します。サブフォルダはそれぞれ一覧に表示し、親直下のMP3と空フォルダにも対応します。MP3以外は対象外です。順番再生は表示されるフォルダ名・曲名の自然順に従います。

オフラインでは保存済みのアプリ画面を起動できますが、音楽の再生には元ファイルと読み取り許可が必要です。外付けドライブは接続しておいてください。

## 検証

- Nodeの自動テスト31件が通過。
- Chrome／Edgeのヘッドレス統合テストで、実MP3再生、一時停止・再開、前後送り、フォルダ選択後の停止、フォルダ内シャッフル、曲末移行、フォーカス、ハンドル保存・復元、権限再許可、キャンセル、オフライン起動を確認。
- 統合テストではブラウザ内のテスト用ファイルとフォルダ選択・権限の代替処理を使用しています。
- 実際のWindowsフォルダ選択ダイアログ、外部フォルダの権限保持、NVDA／ナレーターの読み上げ、PWAインストール、長時間・バックグラウンド再生とMedia Sessionの実機操作は未検証です。

```sh
node --test tests/*.test.js
node --check docs/app.js
```

ブラウザ統合テストは `tests/browser.py` を参照してください。テスト専用のPlaywright、`test-results/tone.mp3`、`docs`を配信するローカルサーバー（127.0.0.1:8766）が必要です。アプリ実行時の外部ライブラリは不要です。
